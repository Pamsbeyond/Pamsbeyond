# PamsBeyond - Visa & Travel Global Services ✈️

**PamsBeyond** is a dark & red themed web application built with **Streamlit** for comprehensive Visa assistance, Flight comparison (city-based), Accommodation search, and On-Ground local support.

## 🚀 Features & Updates

1. **Tell us where the next overseas plans**: Refined hero slogan and global navigation.
2. **Global Visa Engine**: Instant visa requirements search, documents checklist, terms, official fee calculation, and direct officer support options.
3. **Flight Booking Search**: Scan top connection routes between major global **cities** (Cairo, Toronto, Dubai, London, New York, etc.).
4. **Hotel Stays**: Real-time accommodation search with an interactive price slider filter.
5. **Local Ground Support**: Interactive OpenStreetMap discovery for airport pickup, taxi dispatch, and local services.
6. **Live Chatbot Widget**: Interactive chat box at the bottom-right for instant support.
7. **Human Officer Connection**: Direct forms allowing users to talk to experienced human officers.

## 🛠️ Local Installation & Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/pamsbeyond.git
cd pamsbeyond
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Streamlit app

```bash
streamlit run app.py
```

The app will open in your browser at:

```text
http://localhost:8501
```

- The local assistance map uses OpenStreetMap and Leaflet.
